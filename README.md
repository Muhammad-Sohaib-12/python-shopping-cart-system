# 🛒 Python Shopping Cart System

A console-based shopping cart system built with **Python**, simulating a simple store with customer shopping and admin management.

## ✨ Features

### Customer

* View store inventory
* Browse products by category
* Add and remove items from cart
* View cart and calculate total
* Random product discounts
* Cash and card checkout

### Admin

* Admin authentication
* Add new products
* Remove products
* Update product prices
* View inventory

## 🛠️ Concepts & Technologies

* Python 3
* Lists, dictionaries and tuples
* Functions
* Loops and conditional statements
* User input and validation
* Basic authentication
* Random number generation
* Inventory and cart management
* Payment processing
